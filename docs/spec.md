# 行为边界

## 文字与链接间距

博客与项目文档按显示文字决定间距，普通文字、链接与加粗等形式使用同一规则：

- 中文与英文字母或数字相接时使用一个半角空格，中文与中文相接时紧贴。链接左右边界分别判断。
- 完整的中英混排网名作为整体，与相邻汉字、字母或数字各用一个半角空格分隔，内部保留本人写法。该例外只覆盖网名本身，包含网名的链接仍按两端实际文字判断。
- 空格只用于相邻文字之间；中文标点与相邻文字紧贴，英文句子沿用英文分词与标点规则。

```markdown
使用 [GitHub](url) 托管。
参见 [Hexo 文档](url)了解配置。
查看[最新的 issue](url) 提到的问题。
参见[配置指南](url)了解详情。
也可以说是 **银狂TDF** 吧。
借用 [鸢梦Yumeko](url) 的观点。
借用 [鸢梦Yumeko 的观点](url)解释问题。
Read [the guide](url) first.
```

## 公式写作

复杂公式中的 `_`、`*`、`\\` 可能需要额外 Markdown 转义，参见[插件说明](https://github.com/next-theme/hexo-filter-mathjax#renderer)。正文中的美元符可能被识别为公式，字面示例宜放在行内代码或代码块中。

## 验证范围

自动验证只承担最小站点正确性检查。

## 依赖自动合并

- 自动合并以 Dependabot 生成的依赖树与 Action 版本判断为依据。完整 SHA 与绿色构建不证明上游安全，也不保证未经运行路径的 major 兼容性。
- 保护或策略条件无法满足、验证失败时，保留更新 PR 并暂停自动合并。
- 追加提交后的重新验证仍有竞态。

## 发布

陈旧产物检查只发生在部署开始前，不是覆盖整个部署期间的原子锁。发布失败不会自动回滚。
