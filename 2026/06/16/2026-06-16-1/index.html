Cloudflare Zero Trust 加密 DNS 配置

前言

加密 DNS 也是隐私设置不可不品鉴的一环了。前几天先试了试经典的 Cloudflare 公共 DNS，实际用起来时通时断的。翻了翻发现 Cloudflare Zero Trust 有提供个性化的免费加密 DNS，这不得整个看看？

先把 Cloudflare 这边搞好

Cloudflare，启动！

  1. 注册好 Cloudflare 账号进入 Zero Trust，提示要支付方式的话随便整张信用卡绑上
  2. 找到 网络> 解析程序和代理 菜单，没有默认 DNS 位置就选择 添加位置
  3. 位置名称随便填，IPv4 DNS 和 IPv6 DNS 这俩勾不勾都行，基于 HTTPS 的 DNS (DoH) 得勾上，如果要给安卓手机配置的话 基于 TLS 的 DNS (DoT) 也勾上，保存即可

这样 Cloudflare 这边就搞完了，看到那个它给你的 DoH 地址 https://xxxxxxxxxx.cloudflare-gateway.com/dns-query 的吗？记下来，后面要用的。

接下来搞 Windows 系统设置

打开 Windows 设置找到 网络和 Internet> WLAN> 硬件属性，点 DNS 服务器那栏的 编辑，改成 手动分配 就能看到 Windows 的 DoH 配置了。

Windows 系统的 DoH 模板同时需要服务器的 IP 地址和请求的 DoH 地址。如果你当时勾了 IPv4 DNS 和 IPv6 DNS 这俩选项，别急着把他俩填进 IP 的位置。那是给你访问普通 DNS 解析用的，和 DoH 地址凑不成一对（我当时一时铸币，这么干了还纳闷怎么没用呢……）。

至于咋找 DoH 地址对应的 IP，简单粗暴 Ping 就完事了：

ping -4 xxxxxxxxxx.cloudflare-gateway.com  # 找出 IPv4
ping -6 xxxxxxxxxx.cloudflare-gateway.com  # 找出 IPv6

找到 IP 地址就可以回到面板继续配置了，IPv4 和 IPv6 俩都勾上，首选 DNS 填刚找着的 IP 地址，DNS over HTTPS 选 开(手动模板)，然后在模板里塞上 Cloudflare 给你的 DoH 地址。既然都配 DoH 了嘛，失败时使用未加密请求 也可以顺手关掉，出问题了再临时开回来救一下。

给 Firefox 也整上

Chromium 系什么的应该也有办法整，但我只认识 Firefox 思密达。来都来了，在 隐私与安全> “基于 HTTPS 的 DNS”启用策略： 里选个 最大保护 呗，自定义 这儿填上 DoH 地址就行了。

你这是典型的安卓设置

安卓的加密 DNS 用的是 DoT 不是 DoH，选项位置各大国厂应该都不一样，不过也都大差不差就是了。荣耀手机的话就是在设置里找到 更多连接> 加密 DNS，在 指定加密 DNS 服务 的框里填上 xxxxxxxxxx.cloudflare-gateway.com 的主机名即可。

结语

那么，古尔丹，代价是什么呢？会 变 慢 的 啊。
